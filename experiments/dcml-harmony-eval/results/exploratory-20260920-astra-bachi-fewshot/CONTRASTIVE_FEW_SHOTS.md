# Static contrastive harmony examples

These miniature examples teach distinctions that commonly fail. They are not
templates to copy. Apply the deciding contextual rule to the supplied score.

## 1. Tonicization is not automatically modulation

```abc
K:C
[CEG]2 [A^ceg]2 | [DFA]2 [GBdf]2 | [CEG]4 |
```

Prefer `I – V7/ii – ii – V7 – I` in C major. The A7 briefly tonicizes ii, but the
return to C supplies no sustained evidence for changing the local key to D minor.

## 2. A relative-major chord is not automatically a key change

```abc
K:Am
[Ace]2 [FAc]2 | [E^GBd]2 [Ace]2 |
```

Prefer `i – VI – V7 – i` in A minor. The F-major chord is not enough by itself to
reinterpret the passage in C major. Change local key only when several spans and a
cadential or phrase-level continuation support it.

## 3. Do not infer an absent seventh

In C major, sounding `G–B–D` supports `V`; `V7` requires a structural F that is
sounding or retained. Functional expectation alone does not add the seventh.

## 4. Preserve alteration and inversion independently

In E-flat major, an E-natural diminished seventh leading to ii retains the raised
alteration: `#vii°43/ii` is not interchangeable with `vii°43/ii`. Determine the
literal bass separately to retain `43` rather than collapsing it to root position.

## 5. Recognize augmented-sixth voice-leading

In C minor, A-flat–C–F-sharp resolving outward to G is `It+6`, not a diminished
seventh merely because the sonority is chromatic. Resolution and spelled scale
degrees decide the special-chord label.

Before emitting spans, check: keep a stable local key until context proves a change;
do not invent chord members; preserve chromatic spelling, applied target, and literal
bass; and place a boundary only when function or structural sonority changes.
