# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Chorale, please report it responsibly:

- Email: `hxy9243@gmail.com`
- GitHub Security Advisory: Open a private advisory under the repository's [Security Advisories](https://github.com/hxy9243/chorale/security/advisories) tab.

Please include steps to reproduce along with any relevant technical context.
