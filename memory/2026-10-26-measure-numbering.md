# Measure numbering investigation — 2026-10-26

- **Symptom:** Chorale printed a number on the opening system and labeled a split-measure continuation with the following complete measure's number.
- **Root cause:** `installLineStartMeasureNumbers` labeled every system and explicitly advanced from a repeated canonical measure mapping to the next bar's mapping. Earlier changes `2065f59` and `d6ffd97` introduced these display choices; the shared measure mapping already preserved split-measure identity.
- **Convention:** LilyPond's [bar-number documentation](https://lilypond.org/doc/v2.26/Documentation/notation/bars#bar-numbers) describes suppressing the opening number. Its broken-measure example either suppresses the continuation label or repeats the same number in parentheses. Placement is an engraving choice; a continued measure does not become the next measure. Chorale retains its plain-number style as requested.
- **Fix:** `src/components/SheetMusicView.tsx` skips the opening system and uses the canonical mapping directly for later system labels. Updated `spec/score-surface.md`. Measure identity, selection, playback, and source ABC are unchanged by this patch.
- **Regression tests:** `src/components/__tests__/SheetMusicView.test.tsx` covers ordinary system labels, pickups, split repeats, split repeats after a pickup, and a final continuation with no subsequent complete measure. The five cases failed before the fix; the split cases demonstrated expected 2 versus actual 3. All 45 component tests passed after the fix.
- **Evidence:** Full `npm test` passed: 255 Node tests and 998 Vitest tests across 106 files. `npx tsc -b`, `npm run lint`, and `npx vite build` passed. Lint reported existing warnings; build reported a large-chunk warning.
- **Visual check:** Headless Chrome rendered the actual React component and abcjs notation for all five fixtures. The temporary harness forced the system breaks through abcjs's layout options to exercise the boundaries deterministically. Every first system was unnumbered; second-system labels were 3, 2, 2, 2, 2; no page errors. Screenshot inspected visually. This was an isolated notation check, not a complete desktop interaction test.
